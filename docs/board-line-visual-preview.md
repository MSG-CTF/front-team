# 팀별 보드 라인 완성 시안

기준: 2026-09-29, main 046c860 위의 로컬 작업

## 적용 범위

각 팀은 자신의 보드를 따로 보므로 상대 팀 소유권, 팀 깃발, 땅 빼앗기 표시는 사용하지 않음
원판 바깥의 진행률 띠와 칸 위의 색 막대를 제거하고, 완료 왕관과 필요할 때만 보이는 면 조명으로 표시

- 같은 라인을 구분하던 색 막대와 풀이 완료 체크, 추가 테두리는 모두 제거
- 방문한 면은 원본 나무결과 문양을 남긴 어두운 재질로 표시
- 기존 열린 문제 패널에서 라인 완성을 펼치고 라인을 선택할 때만 대상 칸에 은은한 면 조명을 표시
- 항목을 접거나 패널을 닫으면 면 조명을 제거
- 개별 해결 수는 펼쳐보기와 접근성 설명에서 확인
- 완료가 명시된 라인은 구역 안쪽에 왕관과 월계수 문장 표시
- 원래 START 칸의 금속 재질을 참고해 만든 투명 이미지 사용
- 큰 글자 리본은 제거하고 라인 독점 문구는 마우스를 올리거나 키보드로 선택할 때만 표시
- 완료 순간에만 해당 칸들이 800ms 함께 빛나며 최초 로딩이나 같은 완료 상태의 재렌더링에는 반복하지 않음
- 완료 문장은 650ms 동안 한 번 나타나며 임시 연출 상태는 최대 850ms 후 정리
- 모션 줄이기 설정에서는 완료 연출을 생략

선택 조명과 완료 연출은 모두 기존 방문 표시와 같은 실제 칸 윤곽으로 잘라냄
원래 숫자, 금테, 보석과 다람쥐 이미지는 교체하지 않음
라인 묶음에 포함되지 않은 특수 칸은 강조하지 않으며 작은 상태 점도 추가하지 않음

이미지 출처와 생성 프롬프트는 [완료 문장 이미지 기록](./board-line-asset.md)에 보관

현재 BoardScreen의 선택 속성으로 만든 UI이며 실제 BoardPage에는 라인 데이터를 연결하지 않음
실제 API 요청, 독점 판정, 보너스 지급, 마일리지 변경은 하지 않음

## 데이터와 판정 경계

아래는 프론트 내부 화면 모델이며 백엔드 HTTP 계약으로 확정한 필드가 아님

| 화면 값 | 의미 |
| --- | --- |
| lineId, label | 라인 식별자와 표시명 |
| cellIndexes | 명시적으로 받은 대상 칸 |
| solvedCellIndexes | 그 라인에서 해결한 칸 |
| isCompleted | 완료 여부를 명시한 값 |
| bonusScore | 완료 후 지급이 확인된 보너스, 모르면 null |

- 방문 기록, 현재 위치, 경유 기록으로 해결 여부나 독점을 추측하지 않음
- 대상 칸을 모두 해결했더라도 완료 값이 없으면 완료 확인 중으로 표시
- 완료 값이 있어도 해결 목록이 불완전하면 독점 완료로 표시하지 않음
- 미제공 점수와 0점은 구분하며 시안에서는 보너스 숫자를 표시하지 않음
- 라인 데이터가 없으면 장식과 완료 문장, 라인 완성 항목을 모두 숨김
- 중복 라인 식별자, 겹치는 칸 소속, 잘못된 칸 번호는 표시에서 제외
- 6개 라인이나 5개씩 묶는 규칙을 실제 화면 기본값으로 넣지 않음
- 흩어진 칸의 묶음은 연속 영토처럼 보이지 않도록 완료 문장을 생략하고 펼쳐보기에서 확인

## 모바일과 조작

- 라인 데이터 유무와 관계없이 기존 x=448, y=120, 951×960 모바일 장면을 유지
- 원판과 배경의 원본 기준점은 기존 (448, 289) 유지
- 배경, 원판, 방문 표시, 라인 장식과 완료 문장이 같은 장면 안에서 확대되고 움직임
- 상단에는 원래 열린 문제 목록 보기와 모바일 확대 버튼만 유지
- 별도의 라인 현황 버튼과 독립 현황창은 제거
- 라인 완성은 기존 열린 문제 패널 안의 접힌 항목으로 표시
- 왕관을 선택하면 같은 패널의 라인 완성을 펼치고 해당 라인으로 선택
- 키보드 Enter와 Space로 펼치고 접으며 Escape로 패널 닫기, 닫은 뒤 원래 조작 위치로 포커스 복귀
- 작은 문장을 누르기 어려운 경우 열린 문제 목록 보기와 44px 높이의 펼쳐보기에서 동일한 내용 확인
- 전체 문제 보기로 별도 목록 페이지에 이동하는 버튼 제거
- 기존 목록 페이지 주소와 다른 화면의 링크는 호환성을 위해 유지
- 칸 선택은 기존 문제 정보 조회 및 열린 문제 상세 진입 유지
- 모바일에서도 기존 열린 문제 패널 하나만 사용

## 로컬 확인

Vite 개발 서버를 실행한 작업 폴더에 있는 로컬 확인용 화면

http://127.0.0.1:57631/.playwright-cli/board-visited.html?lines=1

오른쪽 아래 로컬 화면 확인에서 일부 해결, 모두 완료, 완료 확정 대기, 라인 데이터 없음을 선택
첫 라인 마지막 문제 해결 버튼으로 4/5에서 독점 완료로 바뀌는 연출 확인
이 화면의 칸 묶음은 디자인 확인용 예시이며 실제 대회 구성으로 확정한 값이 아님
확인용 파일은 Git에서 제외된 로컬 도구이고 배포 페이지에는 포함하지 않음
주소에 &challenges=1을 추가하면 확인용 문제 두 개로 목록 선택 콜백도 확인 가능

## 브라우저에서 확인한 내용

- 프론트 전체 테스트 206개 통과, 프로덕션 빌드 통과
- 기존 500kB 초과 번들 경고는 남아 있음
- 1280px에서 전체 6개 라인 완료 시 문장끼리 겹침 없음
- 문장의 설명 글자까지 포함한 경계와 36개 칸 클릭 영역, 주사위 클릭 영역의 사각 경계 교차 없음
- 4번 칸과 겹치던 문장 위치는 안쪽으로 옮긴 뒤 재검사
- 320px와 390px에서 문서 가로 넘침 없음
- 390px와 320px 확대 상태에서 원판과 라인 표시의 위치·크기 차이 0px 확인
- 320px 펼쳐보기의 내용 너비가 패널 너비를 넘지 않음
- 문장 선택 시 기존 열린 문제 패널에서 라인 완성이 열리고 Escape 후 문장으로 포커스 복귀
- 첫 라인 4/5에서 완료로 전환 시 해당 5칸의 연출과 문장 1개 생성
- 연출 종료 후 해당 SVG 강조 경로 제거 확인
- 모든 칸 해결 상태라도 완료 미확정이면 완료 문장 0개
- 라인 데이터 없음 선택 시 장식과 문장, 라인 완성 항목이 없어지고 보드 너비는 변하지 않음
- 320px 확대 후 가로 80px 이동에도 배경과 원판의 상대 위치 약 292.06px 유지
- 완료된 칸을 선택해도 기존 칸 정보창이 열리며 장식이 조작을 막지 않음
- 검수 시 브라우저 콘솔 오류 없음
- 실제 서버 판정이나 지급을 호출하는 통합 검증은 아님

## 막대 제거 후 재확인

- 색 막대, 체크와 추가 테두리 경로가 렌더링되지 않음을 자동 검사
- 펼쳐보기에서 2번 라인 선택 시 해당 5칸만 조명이 표시되고 접으면 0개로 복귀
- 방문한 4번 칸의 정보창을 계속 열 수 있음
- 라인 데이터 없이 전체 미방문은 표면 처리 0개, 전체 방문은 36개
- 방문 면 안쪽의 음영은 선을 덧그리지 않고 반투명 면으로만 적용
- 320px와 390px에서 방문 면, 라인 표시와 원판의 위치·크기 차이 0px 및 가로 넘침 없음
- 390px 확대 상태에서 80px 가로 이동 후에도 배경과 원판의 상대 위치 292.0625px 유지
- 브라우저 콘솔 오류 없음, 전체 테스트 206개와 프로덕션 빌드 통과

## 실제 연동 전에 정할 것

기능 명세의 라인 독점 규칙은 아직 미정이므로 아래 결정 후 별도 연동 필요

- 라인별 대상 칸과 특수 칸 포함 여부
- 팀별 라인 완성에 지급할 보너스
- 완료, 해제, 중복 지급에 대한 서버 판정 기준
- 지급 점수와 완료 상태를 전달하는 API 계약

규칙이 확정되면 백엔드 응답을 화면 모델로 변환하고 실제 응답 기준 회귀 테스트를 추가

## 기존 펼쳐보기 통합 확인

- 상단의 별도 라인 현황 버튼과 독립 패널 제거
- 열린 문제 패널 안에서 라인 완성은 기본적으로 접힌 상태
- 왕관 선택 시 같은 패널의 해당 라인으로 이동하고 Escape로 닫은 후 왕관에 포커스 복귀
- 항목을 펼쳤을 때만 5개 대상 칸을 강조하고 접으면 강조 0개
- 확인용 1001번 문제 선택 시 기존 상세 진입 콜백에 1001 전달
- 320px에서 패널 296px, 내용 영역 225px로 가로 넘침 없음
- 390px에서도 패널과 내용의 가로 넘침 없음
- 라인 데이터가 없는 실제 기본 경로에서도 기존 문제 목록과 상세 선택은 유지
- 별도 전체 문제 보기 버튼만 제거하고 기존 목록 경로는 삭제하지 않음
