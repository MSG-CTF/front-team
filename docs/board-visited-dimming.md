# 방문한 보드 칸 표시

기준: main 046c860, 2026-09-29

## 적용 범위

- 서버의 소모 목록 또는 CONSUMED / OPENED / CLEARED 상태가 있는 칸만 어둡게 표시
- 말의 현재 위치와 경유 경로만으로는 방문 처리하지 않음
- START도 서버의 소모 기록이 생겼을 때만 적용
- 서버에서 방문 기록을 초기화하면 원래 밝기로 복원
- 방문한 칸의 정보 조회, 열린 문제 재진입, 기차여행 목적지 제한은 기존 처리 유지
- 배경과 다람쥐에는 필터를 적용하지 않음

## 그림 기준

기존 board-grid.png를 칸 경계에 맞춰 잘라 어둡게 표시하며 이미지 파일은 변경하지 않음
원본 1772 × 1330 이미지에서 36개 칸의 금색 테두리 안쪽 면을 각각 추적
금테, 보석, 입체 옆면은 원래 밝기를 유지하며 옆 칸이나 바닥까지 덮지 않음
START, 기차, 룰렛과 비스듬한 칸은 확대해 보며 윤곽을 별도로 보정
SVG 경로의 꼭짓점을 원본 기준 최대 2px 곡선으로 연결해 모서리를 정리
방문한 면은 채도와 광택을 낮춘 짙은 나무색으로 바꾸되 숫자와 원본 문양은 남김
면의 가장자리로 갈수록 깊어지는 그늘과 옅은 표면 조명으로 사용한 칸의 재질을 표현
색 막대, 체크, 추가 테두리와 작은 상태 점은 표시하지 않음
그늘은 같은 윤곽 안에서만 적용하며 바깥 금테를 덮지 않음
보드 그림이 바뀌면 boardCellFaces.js의 윤곽 좌표를 다시 맞춰야 함
원본 파일의 SHA-256 검사로 그림만 교체하고 좌표를 그대로 두는 변경을 감지

## 모바일 배경과 보드 이동

- 기본 화면은 맵 너비를 화면에 맞춰 전체 표시하며 가로로 잘라 보여주지 않음
- 바닥 배경과 원판을 BoardScene 안에 함께 배치해 확대와 스크롤을 같이 적용
- 모바일에서는 기존 화면 고정 배경을 숨겨 원판 아래 바닥 문양이 따로 움직이지 않게 함
- 원본 무대의 x=448, y=120, 951×960 영역을 표시하며 원판과 바닥의 원래 상대 위치를 유지
- 라인 완성 시안도 같은 원판·배경 기준점을 쓰며 별도 바깥 띠나 추가 여백을 두지 않음
- 위쪽 풍경을 120px 덜 보여주되 배경과 원판을 같이 잘라 서로 분리되지 않게 함
- 확대를 누른 경우에만 150% 또는 최소 620px로 표시하고 좌우 이동 허용
- 확대 시 현재 말 위치를 보여주고 전체 보기로 복귀하면 가로 이동값 초기화
- 데스크톱 폭으로 전환하면 확대 상태를 초기화하고 기존 데스크톱 배치 유지

## 모바일 디자인

- 보드를 감싸던 좌우 여백과 상단의 큰 갈색 박스를 제거
- 배경의 위아래 경계를 어두운 바탕에 연결하되 칸 그림에는 경계 처리가 닿지 않게 여유 확보
- 규칙, 마이페이지, 순위는 데스크톱의 기존 금색 아이콘과 이름을 가로로 묶어 표시
- 아이콘은 작게 줄이되 메뉴의 터치 영역은 44px 이상 유지
- KoTH, 동아리 부스, 로그아웃은 기존 기능과 경로 유지
- 열린 문제 목록과 확대 버튼은 같은 줄에 배치
- 주사위 횟수와 제한 시간은 한 줄로, 긴 상태 안내는 줄바꿈으로 표시
- 주사위를 바로 굴릴 수 있을 때의 반복 안내만 모바일에서 숨기고 스크린리더 상태 설명은 유지
- 이동 제한 사유와 남은 시간은 숨기지 않음
- 390px에서 메뉴와 안내 영역은 약 79px, 보드 시작 위치는 풍경 조정까지 포함해 약 128px 위로 이동

## 확인

- 방문 판정과 36개 칸 윤곽, 곡선 경로, 원본 이미지 일치 회귀 테스트 11개 통과
- 모바일 기본 너비, 배경 결합과 확대 위치 계산 회귀 테스트 8개 통과
- 모바일 메뉴의 기존 아이콘과 링크, 44px 조작 영역 렌더링 테스트 통과
- 방문 표시의 중복·잘못된 번호 제외, SVG 경로와 빈 상태 렌더링 테스트 통과
- 주사위 상태의 반복 안내 생략과 제한 시간 유지 렌더링 테스트 통과
- 프론트 전체 테스트 206개 통과, 라인 완성 시안 회귀 테스트 포함
- 프로덕션 빌드 통과, 기존 대형 번들 경고는 남아 있음
- 36칸을 각각 확대한 브라우저 화면에서 안쪽 면과 테두리 경계 확인
- 원본 좌표의 폴리곤을 픽셀로 검사해 칸끼리 겹침 0px, 원본 불투명 영역 밖 침범 0px 확인
- 위 픽셀 검사는 경로의 기초 좌표 검사이며 브라우저 안티앨리어싱의 픽셀 단위 검증은 아님
- 로컬 UI 데이터로 미방문 / 일부 방문 / 전체 방문 / 기차여행 선택 확인
