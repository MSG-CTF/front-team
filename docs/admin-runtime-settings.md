# 관리자 문제 설정

관리자 문제 목록에서 문제를 열면 기본 정보·배포 설정·풀이 기록을 나눠 확인할 수 있습니다

| 화면 | 확인할 내용 |
| --- | --- |
| 기본 정보 | 문제 제목·지문·공개 상태·채점 플래그·현재 참가자 파일 |
| 배포 설정 | 발행 버전·컨테이너 설정·버전별 참가자 파일·배포 테스트 |
| 풀이 기록 | 풀이자와 풀이 시각, 시간 범위별 조회 |

GitHub 발행본 가져오기에서 문제를 고르면 문제 정보·배포 버전·참가자 ZIP을 가져옵니다
가져온 문제는 자동 공개하거나 배포하지 않습니다 내용을 확인한 뒤 공개와 적용을 선택합니다

배포 설정에서는 아래 항목을 확인합니다

| 항목 | 확인할 내용 |
| --- | --- |
| 릴리스 | 사용 중인 버전과 이전 발행 이력 |
| 이미지 | 컨테이너별 GHCR 주소와 고정 digest |
| 환경변수 | 해당 릴리스에서 전달하는 이름과 값 |
| 비밀값 연결 | 컨테이너의 주입 이름, 저장된 이름, 연결 버전 |
| 저장된 비밀값 | 저장 시각, 버전, 최신 저장값 여부 |
| 격리와 자원 | 격리 프로필, 공개·내부 포트, CPU·메모리 |

실행용 비밀값 목록에는 이름과 버전만 표시하며 원문과 hash는 조회하지 않습니다
채점 플래그는 기본 정보에서 별도로 확인합니다 원문 보기 버튼을 누른 관리자에게만 원문을 보여주며 60초 뒤 또는 화면을 벗어나면 숨깁니다
저장된 원문이 없거나 채점 hash와 일치하지 않으면 원문을 표시하지 않습니다
화면의 연결됨은 저장된 버전이 릴리스에 연결됐다는 뜻이며 실제 컨테이너 주입을 검증했다는 뜻은 아닙니다

## 변경 순서

환경변수 수정에서는 저장소에서 가져오기·.env 파일·직접 입력 중 하나를 선택합니다
저장소 방식은 출제자의 .env·Compose·Dockerfile·코드에 있는 이름과 값을 그대로 읽습니다
컨테이너를 고르고 불러온 값을 검토한 뒤 설정 확인 → 새 설정 버전 저장 순서로 진행합니다
플래그·비밀번호·키도 재입력 없이 가져오며 화면에서는 출제자 원본값 사용으로 표시합니다
원본에서 값을 확인할 수 없는 항목만 별도로 표시하고 기존 비밀값을 연결하거나 직접 입력할 수 있습니다
새 버전을 저장하면 설정 확인으로 돌아오며 적용은 별도로 선택합니다

GitHub 발행본은 등록할 때 백엔드가 같은 커밋의 env/컨테이너명.env를 읽어 버전에 넣습니다
환경변수 탭 위에 반영한 커밋과 파일을 보이고, 새 발행본 알림에도 저장소 환경변수 반영 여부를 붙입니다
값이 없거나 FLAG가 채점 값과 달라 못 채운 항목이 있으면 그 버전은 이 버전 사용이 막히고 이유와 환경변수 채우기 단추를 보입니다
여기서 값을 넣어 새 설정 버전을 만든 뒤 사용합니다 백엔드도 같은 버전의 전환을 400 RELEASE_ENV_INCOMPLETE로 거절합니다

1) GitHub 발행본을 가져오거나 기존 배포 버전을 고릅니다
2) 컨테이너별 환경변수·비밀값 연결과 참가자 파일을 확인합니다
3) 변경이 있으면 새 버전을 저장하고 배포 테스트로 실행을 확인합니다
4) 이 버전 사용을 누르고 적용 내용을 확인합니다

비밀값을 새로 저장해도 기존 릴리스는 이전 버전을 유지합니다
릴리스 전환은 새 인스턴스부터 적용하며 기존 인스턴스와 재시작은 생성 당시 릴리스를 유지합니다

이미지가 GHCR에 있어도 발행 파일에 비밀값 연결 정보가 없으면 주입 경로에 연결되지 않습니다
이 경우 연결 없음으로 표시하며 이름과 버전을 임의로 만들어 표시하지 않습니다

참가자 파일은 배포 버전마다 선택할 수 있으며 새 버전을 저장하는 것만으로 현재 파일이 바뀌지는 않습니다
배포 테스트도 현재 적용 버전을 바꾸지 않고 선택한 버전으로 실행합니다
준비가 끝나면 접속 주소에서 문제 동작을 확인하고 테스트를 종료합니다 자원 정리가 끝나야 다음 테스트를 시작할 수 있습니다

## 백엔드 계약

[백엔드 실행 설정 PR](https://github.com/MSG-CTF/msg-backend/pull/101)의 관리자 메타데이터 조회가 필요합니다

| API | 용도 |
| --- | --- |
| GET /admin/challenges/{challenge_id}/releases/{release_id}/repository_environment?container=web | 출제자의 환경변수·일반 값·출처 조회 |
| POST /admin/challenges/{challenge_id}/releases/{release_id}/repository_environment/preview | 선택 항목 검사 |
| POST /admin/challenges/{challenge_id}/releases/{release_id}/repository_environment/import | 비밀값·새 설정 버전 저장 |
| GET /admin/challenges/{challenge_id}/releases | 릴리스와 컨테이너별 secret_bindings 조회 |
| GET /admin/challenges/{challenge_id}/runtime-secrets | 비밀값 이름과 버전 조회 |
| POST /admin/challenges/{challenge_id}/runtime-secrets | 비밀값 새 버전 저장 |
| POST /admin/challenges/{challenge_id}/releases | 발행 파일 등록 |
| POST /admin/challenges/{challenge_id}/releases/{release_id}/activate | 새 인스턴스에 적용할 릴리스 선택 |

모든 경로는 /api/v1 아래에 있고 관리자 JWT가 필요합니다
