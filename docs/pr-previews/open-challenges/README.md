# 열린 문제 목록 화면 검수

미해결 문제를 카드 목록의 첫 영역에 모으고 풀이 완료 문제는 기본적으로 접힌 별도 영역에 표시

상단 풀이 완료 숫자를 누르면 완료 영역을 펼쳐 해당 위치로 이동하며, 문제 제목·출제 동아리 검색과 분야 필터를 적용해도 두 그룹을 유지

## 기준

- main 기준 커밋: 07436d9735a562e54a47f02b2b5ed072ca2c3d69
- [기능 명세](https://app.notion.com/p/39f0f19c72be8014bd0dd1fa76f6d3a9)
- [열린 문제 조회 API](https://app.notion.com/p/3b10f19c72be8127a5c3e1d5496c7f6e)
- 서버의 is_solved 값으로만 풀이 완료 여부 판정
- total_score는 해결한 문제의 현재 배점 합계이며 실제 획득 당시 점수로 표시하지 않음

## 글꼴

- 제목·본문·문제명·점수를 Pretendard Variable 1.3.9로 통일
- 공식 WOFF2 원본을 애플리케이션에 포함하고 SIL OFL 1.1 라이선스 동봉
- 숫자는 같은 서체의 동일 폭 숫자를 사용하고 크기·굵기·자간으로 정보 구분
- 로컬 검수 화면과 기존 모의 API 미리보기에서 글꼴 로드를 확인하고 320·390·768·1280px 줄바꿈 재검수
- [글꼴 출처 및 라이선스](../../../public/assets/fonts/pretendard/README.md)

## 화면

실제 페이지와 API 클라이언트에 명세 형태의 로컬 샘플 응답을 연결해 캡처한 화면

미해결 8개·풀이 완료 6개 샘플이며, 이미지의 문제명과 점수는 검수용 데이터

완료 영역 이미지는 키보드 탐색 중의 포커스 표시를 포함하며, 포커스 선이 첫 카드와 겹치지 않도록 제목 영역 안쪽에 배치

## 확인 결과

| 항목 | 결과 |
| --- | --- |
| 미해결과 완료 분리 | 8개·6개가 서로 겹치지 않으며 완료 영역은 최초 진입 시 접힘 |
| 팀원의 풀이 완료 반영 | 새로고침 후 미해결 7개·완료 7개로 변경되고 해당 문제는 완료 영역으로 이동 |
| 인스턴스 위치 | 현재 인스턴스가 있는 미해결 문제를 첫 카드로 표시하고 상세 화면으로 이동 |
| 검색·분야 | 공백·영문 대소문자를 정리해 제목과 동아리 검색, WEB3·OSINT 분야 포함 |
| 완료 문제 검색 | 완료 영역에서 결과 확인, 조건 초기화 시 원래 목록 복원 |
| 빈 상태 | 열린 문제 없음·모두 완료·검색 결과 없음을 구분 |
| 일시적 목록 조회 실패 | 503 이후 기존 목록·검색 조건·완료 영역 펼침 상태 유지, 다시 조회로 복구 |
| 접근 권한 변경 | 403 이후 이전 목록을 제거하고 오류 안내 표시 |
| 인스턴스 조회 실패 | 인스턴스 조회만 503이어도 문제 목록은 사용 가능, 다시 확인으로 복구 |
| 인스턴스 응답 지연 | 응답이 5.5초 지연되어도 문제 목록을 먼저 표시 |
| 키보드 | Enter·Space로 완료 영역 펼침·접기, 상단 바로가기에서 완료 영역으로 포커스 이동 |
| 작은 화면 | 320·390·768·1280px에서 가로 넘침 검사, 긴 제목과 74,070점 합계의 줄바꿈 확인 |
| 자동 검증 | node --test src/features/challenges/utils/*.test.js 통과 17개 |
| 빌드 | npm run build 통과 |

기존 4173 로컬 미리보기에도 동일 소스를 적용해 모의 API의 열린 문제 14개·완료 6개·배점 합계 700을 확인하고, 문제 카드에서 기존 상세 화면으로 이동하는 동작을 확인

별도 샘플 응답 검수와 로컬 모의 API 확인 결과이며 실제 배포 백엔드 연동 검증은 포함하지 않음
