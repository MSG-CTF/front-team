### 문제 리스트 (보드) 페이지

문제 리스트 페이지가 보드판 형태 (모두의 마블 시스템 반영). 주사위 제공하고 주사위를 굴리면 해당 칸으로 이동 후 문제 선택하여 푸는 방식.

**보드판 및 내 팀 상태 조회**

- 36칸 보드의 배치, 칸 종류와 난이도를 표시한다.
- 내 팀의 현재 위치, 보유 주사위 횟수, 다음 충전 시간, 보유 찬스카드, 현재 문제의 남은 시간을 표시한다.
- 방문하여 소모된 칸, 문제를 개방한 칸, 문제를 해결한 칸을 구분해 표시한다.

**주사위 보유·충전·소비**

- 주사위 굴리기 횟수는 팀 단위로 공유하며 대회 시작 시 3/3으로 시작한다.
- 일반 주사위 굴리기를 실행하면 보유 횟수를 1회 소비한다. 예: 3/3 → 2/3 → 1/3.
- 첫 소비 시점부터 15분을 계산하여 1회 충전하며, 이후에도 최대 3회 한도 내에서 15분마다 충전한다.
- 현재 칸의 활성 문제를 개방 후 15분 이내 처음 해결하면 주사위 1회를 충전한다. 동일 문제의 중복 제출로 추가 지급하지 않는다.
- 출발칸 도착, 찬스카드 뽑기, 주사위 보너스 카드의 기존 +1 보상은 유지한다.
- 자동 충전, 문제 풀이, 특수칸·카드 보상, 관리자 수동 지급을 포함해 어떤 경로로도 보유 횟수가 3회를 넘지 않는다. 예: 2/3에서 +1은 3/3, 3/3에서 +1도 3/3이다.
- 충전 도중 추가로 소비하거나 보상을 받아도 보유량이 3회 미만이면 진행 중인 타이머를 유지한다.
- 충전 또는 보상으로 3/3이 되면 타이머를 멈추고, 다음 소비 시점부터 새로 15분을 계산한다.
- 여기서 3개는 보유한 **굴리기 기회 3회**를 뜻한다. 실제 한 번의 이동 눈금은 기존 PR의 주사위 2개 합을 사용한다.

**주사위 굴림 및 말 이동**

- 주사위 굴리기와 이동 확정은 팀장만
- 굴린 결과와 이동 경로를 표시한다. 굴린 뒤 사용할 수 있는 카드가 있으면 카드 사용 또는 이동 확정 단계를 거침
- 눈금만큼 이동한 도착지가 이미 소모된 칸이면 같은 방향으로 진행해 다음 미소모 칸에 도착한다.

**문제 선택 및 풀이 상태 연동**

- 현재 문제칸에서 해당 난이도의 미개방 문제 후보를 최대 3개 제시하고 그중 1개를 선택한다. 선택은 팀원 또는 팀장 할 수 있다.
- 문제를 선택하면 팀에 개방하고 개방 시점 기준 15분 타이머를 시작한다. 같은 칸에서 다른 문제를 다시 고르지 않는다.
- 보드, 열린 문제 목록, 문제 상세, 플래그 제출, 인스턴스 생성이 같은 팀의 문제 개방 상태를 사용한다.
- 정답 제출 시 해당 문제를 해결 상태로 바꾸고 보드에 반영한다. 현재 진행 문제를 해결하면 진행 타이머에 따른 굴리기 제한을 해제한다.
- 개방 후 15분이 지나도 미해결 문제의 정답을 제출할 수 있다. 이때 문제 해결 점수·마일리지와 주사위 추가 보상 조건을 구분한다.

**출발칸**

- 출발칸을 통과하면 기존 PR 기준 100 마일리지를 지급한다.
- 출발칸 도착 시 주사위 +1 보상을 유지하되 총 보유량은 최대 3회다.

**Airport**

- Airport에 도착한 팀의 팀장은 아직 소모하지 않은 원하는 칸으로 이동할 수 있다.
- 팀당 Airport 이동은 1회만 사용할 수 있다.

**찬스칸 및 찬스카드**

- 찬스칸 2개를 유지하고, 도착하면 팀장이 카드를 뽑을 수 있다. 같은 칸에서 중복으로 뽑지 않는다.
- 보유 카드, 효과, 사용 가능한 시점, 사용·버림 상태를 표시한다.
- 효과에 따라 굴리기 전 또는 굴린 뒤 이동 확정 전에 사용한다. 사용하거나 버린 카드는 재사용할 수 없다.
- 보유 카드가 2장이 되면 사용할 카드 1장만 남기도록 팀장이 1장을 버린다.
- 찬스카드 뽑기 시 주사위 +1 보상을 유지하되 총 보유량은 최대 3회다.
- (무인도 방어·무인도 이동 카드 2종은 삭제한다)
- 5종 찬스카드: 주사위 다시 굴리기, 주사위 2회 굴림 후 선택, 주변 칸 이동, 세계여행, 주사위 보너스 카드를 유지한다.

**룰렛칸**

- 룰렛칸은 2개 존재
- 팀장은 룰렛을 돌려 50·100·150·200 마일리지 중 하나를 받는다.

**라인·분야별 독점 추가점수** (미정)

- 독점에 따른 추가점수 기능을 별도 항목으로 기록한다.
- 5개씩 묶어 총 6개 라인으로 구성하는 안은 미정이다.
- 독점 대상 칸·분야, 판정 기준, 추가점수, 중복 지급·독점 해제 기준은 미정이다. 확정된 수치나 이미 구현된 기능으로 표시하지 않는다.

### 문제 상세 페이지

- 문제 상세 정보 표시
  - 문제 제목, 설명, 카테고리, 난이도, 현재 배점, 첨부 파일 표시
  - 현재 팀의 문제 개방 여부와 풀이 여부 표시
  - `TeamChallengeAccess`가 없는 미개방 문제는 상세 조회 및 인스턴스 생성 제한
  - 비공개 문제는 접근 제한
- 현재 문제의 인스턴스 상태 표시
  - 현재 사용자가 소유한 활성 인스턴스 중 해당 문제와 연결된 인스턴스만 표시
  - 인스턴스 상태, 접속 주소, 공개 endpoint 목록, TTL 만료 시각, hard timeout 만료 시각 표시
  - 다른 문제의 활성 인스턴스는 내 인스턴스 조회 API에서 확인
- 인스턴스 생성
  - 백엔드가 현재 활성 Challenge Release를 기준으로 Scheduler에 생성 요청
  - Scheduler 호출에는 참가자 JWT가 아닌 내부 서비스 토큰 사용
  - 멀티 컨테이너와 여러 공개 포트 지원
  - 다른 활성 인스턴스가 있으면 새 인스턴스로 교체
  - 교체되는 이전 인스턴스는 `STOPPING` 상태와 교체 종료 사유로 변경
  - 미개방 문제, 비공개 문제 또는 활성 릴리스가 없는 문제는 생성 요청 차단
  - 권한 검증에 실패한 경우 Scheduler를 호출하지 않음
- 인스턴스 종료
  - 현재 사용자가 소유한 인스턴스에 대해서만 종료 요청 가능
  - 백엔드가 Scheduler에 종료 요청을 전달하고 상태를 동기화
- 인스턴스 초기화(reset)
  - 현재 인스턴스와 동일한 Challenge Release 설정으로 새 인스턴스 생성
  - 기존 인스턴스는 교체 상태로 변경
  - 기존 인스턴스의 접속 주소 및 endpoint는 새 인스턴스에 복사하지 않음
  - Scheduler가 새로 발급한 접속 정보로 갱신
- TTL 표시 및 연장
  - 기본 만료 시각과 hard timeout 만료 시각 표시
  - 연장 요청 시 hard timeout 범위 안에서만 연장 가능
  - Scheduler 응답을 기준으로 갱신된 만료 시각 표시
- 플래그 제출
  - 현재 팀이 개방한 문제에만 플래그 제출 가능
  - 정답이면 Solve 기록을 생성하고 변경된 점수와 보상을 응답에 반영
  - 이미 해결한 문제는 중복 처리하지 않음
  - 오답을 연속 3회 제출하면 30초 동안 추가 제출 제한
  - 제출 제한 중에는 남은 대기 시간을 표시
  - 문제 개방 시각은 `TeamChallengeAccess.opened_at`을 기준으로 처리

### KOTH 페이지

동아리 6개가 각각 1개씩 출제한 총 6개의 KOTH 문제를 제공. 참가자는 팀 토큰으로 문제 서버에 접속하며, 15분 구간별 획득 점수를 누적.

**동아리별 문제 목록 및 상세 조회**

- 동아리명, 문제명, 문제별 상태를 표시한다.
- 문제 상태는 공개 예정(SCHEDULED), 진행 중(ACTIVE), 종료(CLOSED)로 구분한다.
- 목록과 동아리 상세는 로그인 없이 조회할 수 있다.
- 각 문제의 누적 점수 1위 팀과 점수를 표시한다. 양수 점수를 획득한 팀이 없으면 선두 팀 없이 0점으로 표시한다.

**문제 공개 일정 및 다음 개방 시간**

- 4시간마다 2개 문제를 공개하며, 동시에 진행 중(ACTIVE)인 문제는 2개다.
- 다음 문제 개방까지 남은 시간을 표시한다.
- 자동 상태 전환과 다음 개방 시간 제공은 구현 확인이 필요한 항목이다. 실제 공개 시각은 운영 시간표 확정 후 적용한다.

**내 팀 토큰 확인**

- 로그인한 참가자는 자기 팀의 KOTH 토큰을 확인할 수 있다.
- 참가자가 문제 서버에 팀 토큰을 입력하면 서버가 토큰을 검증해 소속 팀을 식별한다.

**KOTH 문제 접속**

- 진행 중(ACTIVE)이면서 참가자 접속 URL이 등록된 문제의 접속 버튼을 활성화한다.
- URL이 없으면 "접속 주소 준비 중"으로 표시하고 접속 버튼을 비활성화한다.
- 공개 예정·종료 문제의 접속 버튼은 비활성화한다.
- 접속 주소는 운영자가 등록한 참가자 URL을 사용한다.

**15분 구간 점수 수집 및 누적**

- 진행 중인 문제 서버에서 15분 구간별 팀 순위를 받아 플랫폼 배점으로 환산한다.
- 구간 배점은 1위 40점, 2위 25점, 3위 15점, 4위 12점, 5위 8점이며 6위 이하는 0점이다.
- 구간 동점 팀은 차지한 연속 순위의 배점을 합산해 팀 수로 나누고 소수점 이하는 버린다. 예: 공동 1위 2팀은 (40+25)÷2로 각 32점.
- 종료 문제는 마지막 누적 점수를 표시하며 새 채점 대상에서 제외한다.
- 내 팀의 KOTH 합계는 모든 KOTH 문제의 누적 점수 합이다. 대회 전체 팀 점수는 제오파디 점수와 KOTH 점수를 합산한다.
- KOTH 채점 구간은 정각·15분·30분·45분이다.

**내 팀 KOTH 진행 조회**

- 로그인한 참가자에게 내 팀의 KOTH 합계를 표시한다.
- 문제별 누적 점수, 순위, 상태, 최초 득점 시각을 표시한다.
- 양수 점수가 없으면 해당 문제의 순위와 최초 득점 시각은 없다.
- 최초 득점 시각은 처음 양수 점수를 받은 시각이며 이후 점수가 추가되어도 바뀌지 않는다.
- 차단된 팀은 순위 산정에서 제외한다.

**문제별 팀 순위표**

- 로그인한 참가자가 선택한 문제의 팀별 누적 점수와 순위를 조회한다.
- 누적 점수 내림차순으로 표시하며, 동점 팀은 공동순위를 적용한다. 예: 1위, 1위, 3위.
- 동점 팀의 화면 표시 순서는 최초 득점 시각, 팀 이름, 팀 ID 순서다. 공동순위는 유지한다.
- 0점 팀과 차단된 팀은 제외한다. 표시할 팀이 없으면 빈 순위표를 보여준다.

### 주사위 충전 시간 안내

- "주사위 초기화" 표현을 "주사위 충전"으로 바꾼다.
- 현재 주사위 보유 횟수/3과 다음 1회 충전까지 남은 시간을 표시한다.
- 서버가 내려준 현재 시각과 다음 충전 시각을 기준으로 남은 시간을 계산하여 참가자 기기의 시계 차이를 보정한다.
- 초 단위 화면 표시는 프론트에서 갱신한다. 초 단위 서버 통신을 확정 요구사항으로 적지 않는다.
- 서버 재조회 주기, 화면 내 표시 위치와 디자인은 별도 결정 사항으로 남긴다.
- 3/3이면 충전 타이머를 중단한다. 이후 1회를 소비하면 새 15분 타이머를 표시한다.

현재 board/dice/status에는 `server_time`과 `next_dice_reset_at`이 있다. 타이머 응답에 `server_time`을 추가하는 PR #54는 대회 타이머 영역이며, 보드가 이 PR에 의존해야 한다고 명세에 적지 않는다.
