## 반영 내용

### 문제 첨부파일

- 파일 이름을 누르면 현재 문제와 파일 ID의 API 경로로 인증 요청
- 다른 출처의 URL에 로그인 토큰을 붙이지 않음
- 기존 공개 파일 링크는 일반 링크로 유지
- 파일 응답으로 받은 JSON 인증 오류도 로그인 갱신 대상으로 처리
- 로그인 갱신 후 해당 파일 GET만 한 번 재시도
- 응답의 형식과 ZIP 헤더를 확인하고 JSON, HTML과 빈 본문은 저장하지 않음
- 중복 클릭 차단, 다운로드 취소, 화면 이탈 시 요청 취소와 임시 URL 정리
- 권한 없음, 파일 교체, 요청 제한과 시간 초과 안내

### 관리자 QR 카메라

- 관리자 마일리지 관리의 QR 결제 탭에 카메라로 읽기 추가
- 카메라 영상은 서버에 전송하지 않고 브라우저 안에서 QR 해석
- 결제 토큰 원문만 입력하며 URL과 다른 종류의 QR은 결제 대상으로 사용하지 않음
- 새 스캔을 시작하면 이전 결제 토큰을 지움
- QR 인식은 폼에 토큰만 채우며 결제를 호출하지 않음
- 기존 품목과 금액 확인, 결제 확인 창, 최종 실행 절차 유지
- 인식 성공, 닫기, 화면 이동, 탭 비활성화와 카메라 전환 때 이전 스트림 종료
- 권한 허용을 기다리던 중 닫혀도 뒤늦게 받은 스트림 종료
- 권한 거부, 카메라 없음, HTTP와 미지원 환경에 안내하고 직접 입력 유지
- 카메라 기능과 해석 라이브러리는 사용할 때만 분리 로딩

### 키보드

카메라 전환으로 포커스된 버튼이 사라지면 Esc가 작동하지 않는 문제를 브라우저에서 발견해 수정함
관리자 모달은 가장 위에 열린 창만 키보드를 처리하며, 버튼이 교체돼도 Esc와 Tab 이동을 유지함
처리 중인 결제 확인 창은 기존처럼 Esc로 닫지 못함

### 브라우저 파일 검사

파일 API가 아직 main에 없어 파일 목록과 다운로드 응답은 브라우저에 주입함
로그인과 토큰 갱신은 실제 로컬 백엔드로 처리함

- Bearer가 포함된 GET으로 ZIP 다운로드
- TOKEN_EXPIRED 후 실제 토큰 갱신과 파일 GET 한 번 재시도
- 403, 404, 503과 HTML 응답에서 파일이 저장되지 않음
- 연속 클릭에도 요청 한 번만 전송
- 다운로드 취소 후 재시도 가능
- 1440px와 360px 화면의 첨부파일 영역 확인

### 브라우저 QR와 결제 검사

실제 로컬 참가자 화면에서 QR을 발급하고 그 이미지를 가상 카메라 영상에 넣음
QR 해석 함수는 교체하지 않고 실제 jsQR로 읽음
물리적인 휴대폰 카메라 촬영 검증과는 구분함

- 권한 거부 안내와 토큰 직접 입력으로 복귀
- 360px 화면에서 카메라 창이 화면 안에 들어옴
- 카메라 전환, Esc 닫기, 탭 비활성화 후 모든 트랙 종료
- 권한 응답을 기다리다 닫은 경우에도 스트림 종료
- 실제 발급한 토큰과 카메라로 읽은 값 일치
- 스캔과 확인 창 표시만으로는 결제 요청이 나가지 않음
- 실행 버튼을 연속 클릭해도 결제 POST 한 번만 전송
- 로컬 잔액 10 MI 차감과 환불 후 원래 잔액 복구
- 결제 성공 후 입력 폼에서 사용한 토큰 제거
- 프론트 런타임 오류 없음

## 결제 화면 가독성 개선

2026-09-20 후속 반영

- 마이페이지와 같은 양피지색, 패널 테두리 원본과 갈색 버튼 사용
- 제목과 주요 버튼은 기존 Song Myung, 금액과 내역은 가독성을 위해 Pretendard 유지
- PC는 QR 읽기와 결제 정보 두 영역, 휴대폰은 세로 배치
- 결제 금액을 가장 크게 표시하고 품목, 확인 버튼 순서로 정렬
- 토큰 직접 입력은 접힌 영역에 배치하고 원문은 비밀번호 입력 형식으로 가림
- QR 인식 후 금액 입력으로 포커스를 이동
- 결제와 환불 확인 창에서 금액, 품목과 처리 내용을 다시 확인
- 성공 응답 후에만 완료 화면과 서버가 반환한 남은 마일리지 표시
- 내부 내역 ID와 원문 사유는 상세 보기에서 확인
- 좁은 화면에서는 결제 내역을 가로로 스크롤하는 대신 두 줄로 배치
- 휴대폰에서는 관리자 메뉴를 접어 결제 화면이 먼저 보이도록 조정
- 결제 화면은 탭을 처음 열 때 분리 로딩하며 다른 탭으로 이동해도 입력 보존

추가 브라우저 검증

- 320, 360, 390, 768, 1024, 1101, 1280, 1440px에서 확인
- 팀명과 품목 각각 100자, 최대 금액 2,147,483,647 MI를 브라우저 응답에만 주입해 가로 넘침 검사
- 긴 값이 들어간 확인 창과 내역 상세 창이 화면 밖으로 벗어나지 않음
- 확인 창을 열고 취소하는 것만으로 결제 요청이 나가지 않음
- 새로고침 후에도 기존 MSG 양피지색과 패널 테두리 유지
- 휴대폰 메뉴 열기와 닫기 확인
- 실제 로컬 QR 발급, 가상 카메라 인식, 결제와 환불을 같은 방식으로 다시 확인

운영 데이터는 사용하지 않으며 화면 폭 검사의 최대 금액은 실제로 차감하지 않음
