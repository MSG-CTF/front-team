## 명세를 반영한 부분

- 시그니처 문제는 보드에서 열지 않아도 도전 가능
- 제출에는 flag만 전송하고 팀 식별자는 로그인 정보로 판정
- 플래그 앞뒤 공백을 임의로 지우지 않음
- 시그니처 보상은 팀 점수만 반영하며 마일리지나 주사위를 프론트에서 추가하지 않음
- 개인 순위는 팀 점수와 구분하고 본인이 푼 JEOPARDY만 표시
- 개인 순위가 없는 응답과 조회 실패를 구분
- KoTH 상세가 ACTIVE이고 접속 주소가 있어야 이동 가능
- 상세 조회 실패, 잘못된 문제 식별자, 종료 상태에서는 지난 접속 주소를 사용하지 않음

## 검증 결과

### 자동 테스트

- npm test 144개 통과
- npm run build 통과
- git diff --check 통과
- npm audit --omit=dev --audit-level=high 취약점 0개
- 새 부스 화면은 경로별로 분리 로딩하며 빌드의 500KB 청크 경고 없음

main 동기화 후 자동 테스트와 빌드를 다시 실행함
부스 화면, 인증 다운로드, 가상 카메라 인식과 로컬 결제·환불도 다시 확인함

### 실제 로컬 백엔드 연결

백엔드 main과 PostgreSQL을 사용한 격리 환경에서 확인함
실제 대회 서버나 운영 데이터는 사용하지 않음

- 공개된 부스 문제 6개 조회와 상세 진입
- 첫 번째와 두 번째 오답은 INCORRECT_FLAG, 세 번째는 TOO_MANY_ATTEMPTS
- 30초 동안 제출 버튼이 비활성화되고 시간이 지난 뒤 재제출 가능
- 정답 후 팀 점수가 825점에서 1125점으로 변경되고 목록에 풀이 완료 표시
- 같은 정답으로 마일리지 330, 개인 점수 200, 보유 주사위는 변하지 않음
- 다른 요청이 먼저 해결한 문제를 화면에서 제출하면 ALREADY_SOLVED 처리하며 점수 중복 지급 없음
- 정답 저장 후 응답만 끊어도 POST를 재전송하지 않고 상세 GET으로 풀이 완료 복구
- 마이페이지에서 실제 개인 순위 1위, 개인 점수 200, 본인 해결 2문제 표시
- KoTH 상세 API 직접 호출과 서버 접속 주소 유지
- 접속 주소가 없는 KoTH 문제는 이동 링크를 만들지 않음

### 브라우저 실패 응답 주입

아래 항목은 프론트 오류 처리 검증이며 백엔드 장애 복구 시험과 구분함

- 같은 폼을 연달아 제출해도 POST는 한 번만 전송
- 개인 순위 null 응답, 500 응답, 정상 복구를 각각 표시
- 문제 비공개 전환 후 이전 설명과 제출 폼 제거
- 다른 문제 식별자가 담긴 상세 응답 거절
- KoTH 카드를 바꾼 뒤 이전 상세 응답이 늦게 도착해도 현재 선택을 덮지 않음
- 목록은 ACTIVE여도 상세가 CLOSED이면 접속 차단
- 상세 조회 실패 후 재시도하면 실제 응답으로 복구

### 화면 확인

- 부스 목록, 상세, 마이페이지를 1440, 1280, 390, 360px 너비에서 확인
- 긴 문제 제목과 동아리 이름, 소수 배점 표시 확인
- 동아리 로고 6개 로딩과 보드 바로가기 이동 확인
- KoTH는 데스크톱에서 기존 카드 배치와 상세 패널 확인
- KoTH 전체 화면의 모바일 재설계는 이번 범위에 포함하지 않음
